# Usama Zulfiqar Portfolio

A modern, animated personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion. This project showcases experience in frontend development, data analytics, UI/UX design, and creative web experiences.

## ✨ Features

- Responsive one-page portfolio experience
- Animated hero section and project cards
- Dark premium visual theme with glassy depth
- Smooth scroll and interactive UI elements
- Easy-to-edit content and project sections

## 🛠 Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons
- Lottie React
